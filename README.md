## Featured Projects

### [InsightBoard](https://github.com/singhrishabh444/insightboard)

An AI-assisted analytics workspace that turns natural-language questions into structured analysis plans, validates those plans against the dataset, and computes answers locally.

`React` `TypeScript` `Vite` `Apache ECharts` `OpenAI API`

### [Transaction Data Engineering Pipeline](https://github.com/singhrishabh444/transaction_data_pipeline)

An end-to-end transaction pipeline with raw and silver data layers, explicit schemas, validation, deduplication, and date-partitioned Parquet storage in AWS S3.

`Python` `PySpark` `AWS S3` `Hadoop S3A` `Parquet`

### [ResumeFit ATS Checker](https://github.com/singhrishabh444/ats-resume-checker)

A privacy-focused browser application that reviews resumes for ATS readiness, job-description alignment, missing content, and formatting risks.

`JavaScript` `HTML` `CSS` `PDF Processing`

### [Emotion Detection System](https://github.com/singhrishabh444/Final_project)

A tested Flask application and REST API for detecting dominant emotions in text using IBM Watson's Emotion Detection service.

`Python` `Flask` `REST API` `Unit Testing`

### [Agentic AI Starter](https://github.com/singhrishabh444/Agents)
